# 恋爱函数

对一个你见过或认识的人：现在要不要往前走一步？

在线使用：https://candyrabbit7.github.io/love-function/

一个纯静态网页。所有计算都在浏览器里完成，不会上传任何内容。仅供成年人参考。

## 它会告诉你什么

回答几个问题（你们到哪一步了、认识多久、你有多心动、TA 的「作妖」程度、TA 最近热情和冷淡的次数、TA 整体给你的感觉，以及两项可选的关于你自己的问题），页面直接给出：

- **结论**：现在该做什么，比如打个招呼、约 TA 单独出来、表白、先多相处；
- **怎么做**：具体的一步；
- **之后**：TA 热情或冷淡的话，下一步分别是什么；
- **为什么**：一句话。

还有一个区位标签：暧昧、认真交往、长期伴侣、独角兽，可以切换成梗版名字（暧昧区、女友区、老婆区）。

## 怎么算的

### 一句话

把「要不要往前一步」写成一个随相处推进的决策问题：每走一步都可能被拒，但也能从 TA 的回应里多知道一点；等太久，TA 可能有了别人或离开这个圈子。模型算出每种情况下怎么做期望上最划算，再把结果写成简单的规则。

### 区位

来自网上流传的「外貌 × 作妖」分区图，作妖从 4 开始。我们没有照搬它，而是用一个「先筛选、再权衡」的价值模型（参考 Bruch, Feinberg & Lee 2016, PNAS）重新算出各区的边界：

- 心动先要过门槛：5 分才值得接触，7 分才谈得上认真。原图要 8 分才算认真，我们放宽到了 7 分，因为心动 7 分的人也会认真交往。
- 过了门槛以后，在心动带来的好处和作妖带来的消耗之间权衡；关系越长，作妖的消耗越被放大。
- 按放宽后的门槛，模型的边界和原图一致约 94%；和原图原样相比一致约 89%，差别主要在心动 7–8 分这一条。
- 独角兽只是一个描述：长期伴侣区里作妖低于 5 的部分。

### 要不要往前一步

- 关系分三个阶段：见过、聊过几次、熟了。每周可以往前一步、等一等、表白或者放弃。
- TA 对你有没有意思，一开始只能靠整体感觉估计，之后每一次回应都会更新这个判断。
- 出于礼貌，不感兴趣的人也常常热情回应（模型里是一半的时候），所以热情说明的问题比冷淡少，偶尔一次冷淡也不是否决。
- 每过一周，TA 有大约 3% 的可能有了别人或离开这个圈子。
- 在一起的价值随心动增长。被拒的难受有一部分是社交上的刺痛，和心动无关；其余随心动增长。错过一个本来可能成的人也会后悔。第 7 题的两个选项调的就是被拒和错过的分量。
- 用动态规划从后往前算出每种情况下的最优做法，提前存成规则表（`data.js`），网页只查表。每条规则都能写成「冷淡 j 次时，热情至少 i 次就往前」。
- 「之后」一栏：把热情或冷淡各加一次，再查一次规则表。「还差几次」是把热情一次次加上去，直到规则说可以往前的次数。

### 主要假设

- 认真交往和长期伴侣在事前分不清，所以模型不给它们不同的价值，只用来描述。
- 被拒的难受来得快、走得快；错过的后悔来得慢、持续久。默认值参考了一位用户的真实打分和相关研究的方向。
- 每周 3% 的「错过」概率是假设的。

### 局限

- 参数大多是假设，结果是模型推算，不是对某个具体的人的判断。
- 研究发现，在真正相处之前，几乎没法预测两个人长期合不合适。
- 心动很高的时候，人很难看清对方的作妖程度，作妖分可能偏低。
- 模型里关系推进得比现实快，「第几周」只是粗略的参考。

### 边界和隐私

- 只给你自己做参考用。不要给具体的人打分并分享或记录下来。
- 对方没有回应或拒绝了，就尊重 TA，不要反复推进。
- 适用于成年人。
- 页面不收集、不上传任何数据。

## 文件

- `index.html`：页面；
- `logic.js`：查表和生成结论；
- `data.js`：预先算好的区位和规则表。

规则表由本地的 Python 模型生成。网页逻辑另有一份 Python 对照实现，测试时用随机输入逐一比对两者的结果。

模型、代码和文字由 AI 协助完成。
